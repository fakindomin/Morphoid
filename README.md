# Morphoid Studio

Parametric FDM collectible generator. Pipeline: **genome (Morphotyp) → rig → 2D / 3D → bake → STL/3MF**.

Status: core PoC (Stage 0) – genome codec, rig with the Y=0 bed anchor, N→2N rule, radial-menu state machine.

```
npm install
npm test          # vitest
npm run typecheck
```

Docs: `docs/ARCHITECTURE.md`, `docs/ROADMAP.md`.
